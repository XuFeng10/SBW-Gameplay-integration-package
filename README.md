# 卓越前线：战斗整合包

一款以 **卓越前线（Superb Warfare）** 为核心的 Forge 1.20.1 战斗整合包，围绕现代军武、载具作战与高难度生存构建。整合包在保留卓越前线完整枪械与载具体系的基础上，引入了硬核夜晚生存、击杀反馈、地图辅助与性能优化模组，力求在战斗体验与生存压力之间取得平衡。

---

## 核心特色

### 以卓越前线为战斗主轴

卓越前线提供了 30 余种枪械、多样化载具（主战坦克、武装直升机、步兵战车等）以及配套的弹药与配件系统。本整合包保留了其完整的战斗生态，并搭配 **Kotlin for Forge** 等前置确保模组稳定运行。

### 硬核生存压力

引入 **One Night To Die**，显著提升夜晚怪物数量与 AI 强度，怪物会装备护甲与武器，Boss 拥有额外技能与更高血量。配合 **Improved Mobs**，让每一场夜间遭遇都具备威胁性，迫使玩家善用卓越前线的火力优势。

### 完整的击杀反馈

**GD656 Killicon** 针对卓越前线提供了专属联动支持，包含精确命中、载具摧毁、载具修理等击杀类型与加分项。配合 **TracerFire** 曳光弹效果，射击反馈更加直观。

### 战场信息与辅助

- **Xaero's World Map**：大地图辅助战场导航
- **QuickHud**：快捷信息显示
- **JEI**：物品与配方查询
- **Patchouli**：内置指南书支持

### 载具扩展与内容联动

**DragonRise: Reforge** 作为载具扩展包，为卓越前线体系补充更多载具选择。**Create** 提供一定的科技基建能力，**Curios** 与 **Geckolib** 则支撑饰品与模型渲染。

## 安装说明

本项目以**整合包**形式发布，每次 Release 均提供打包好的整合包文件，**无需手动逐个下载/放置模组**。请根据你使用的启动器选择对应安装方式。

### 方式一：CurseForge / Modrinth 客户端（推荐）

1. 下载 Releases 页面中的整合包文件（`.zip`）。
2. 打开 **CurseForge App** 或 **Modrinth App**，进入「整合包 / Modpacks」页面。
3. 点击「导入 / Import」，选择下载的 `.zip` 文件。
4. 等待客户端自动下载 Minecraft 1.20.1、Forge 及全部模组依赖。
5. 导入完成后点击「游玩 / Play」即可启动。

### 方式二：第三方启动器（HMCL / PCL2 / ATLauncher 等）

1. 下载 Releases 页面中的整合包文件（`.zip`）。
2. **HMCL**：主页 →「安装新游戏」→「导入整合包」，选择 `.zip` 文件。
   **PCL2**：主页 →「版本管理」→「导入整合包」，选择 `.zip` 文件。
   **ATLauncher**：Instances → Import → 选择整合包文件。
3. 启动器会自动解压并安装对应版本的 Forge 与模组。
4. 首次启动前确认已分配 **6GB 及以上内存**（设置 → Java 参数）。

### 方式三：手动安装（不推荐，仅应急）

若启动器无法导入，可手动还原：

1. 安装 Minecraft **1.20.1** + **Forge 47.2.0+**。
2. 将整合包内 `mods` 文件夹中的全部 `.jar` 放入游戏目录的 `mods` 文件夹。
3. 将 `config`、`defaultconfigs` 等配置文件夹一并复制到游戏目录。
4. 分配至少 **6GB** 内存后启动。

> 手动安装容易遗漏依赖与配置，建议优先使用方式一或方式二。

### 安装后检查

- 启动游戏后，模组列表（Mods）中应能看到 **Superb Warfare**、**DragonRise: Reforge**、**One Night To Die** 等全部模组，且无红色报错。
- 进入世界后，可在配置菜单中调整卓越前线与 One Night To Die 的难度参数。

## 推荐玩法

- **前期**：利用 Create 建立基础资源线，同时通过 JEI 查询卓越前线枪械蓝图与材料包的获取途径。枪械蓝图可在各类宝箱中找到。
- **中期**：解锁载具后，利用坦克或直升机应对 One Night To Die 强化后的夜晚怪物潮。载具的机枪与主炮在面对成群敌人时效率远超手持武器。
- **后期**：挑战强化后的凋灵、末影龙与监守者，配合 DragonRise 扩展载具进行大规模作战。

## 注意事项

- 卓越前线与 One Night To Die 均会显著增加游戏难度，建议根据自身水平在配置文件中调整参数。
